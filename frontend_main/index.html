Part 2 · Companion masterclass

Meet L'OréalGPT's Companions

Small confession: you're in this room, at this exact time, because a Companion of mine went through everyone's calendar and found this slot.

  • A Companion is a custom version of L'OréalGPT you configure once
  • Instructions, documents and settings baked in — no re-explaining yourself every time
  • It works your way, on demand, every single time

Not all Companions are equal

Three flavours, three scopes

  • MyCompanion — just for you, built in minutes, nothing to share
  • Team Companion — shared with your team, still self-served
  • Métier Companion — the whole business function, and it needs formal validation before it exists

Over 22,000 personal Companions have already been created org-wide. This is not a niche feature.

Governance isn't an afterthought

From idea to live Companion

  1. Ideation — Owner, Admins, Beta Testers assembled; the Métier Champion signs off first
  2. Creation — a Service Request spins it up, tagged Draft
  3. Build & Test — instructions written with CRAFT, then graded
  4. Launch — shipped to its real audience
  5. Run — live, monitored, iterated

What's actually inside one

Four building blocks, one method

Think of a Companion as a well-trained partner: it knows its job, has the right references, uses the right tools, and remembers your history.

Instructions

Read on every single request. Editable anytime.

Documents / Library

Reference files — up to 1,000 pages once AKS is on.

Settings

Model choice, web search, thinking steps, file uploads.

Memory

Ask it to remember, click the icon, or highlight text.

Where it stops being a chatbot

Giving it super-powers

Simple Companion + Tool = Advanced Companion. Three tools actually available today:

📚 AKS — Agentic Knowledge Search

Points at a library of up to 1,000 documents; reads titles first, then digs into the right ones.

📱 MCP — app connections

A universal plug that lets it act inside real apps: send an email, schedule a meeting — not just talk about it.

📊 Conversational Analytics

Wired to L'Oréal's data platform — a data analyst you can talk to. Needs sign-off first.

Before anyone else can use it

  • Minimum 80% accuracy on an automatic test set to launch (waived for creative use cases)
  • At least 50 Q&A pairs, including out-of-scope ones — it has to know how to say “I don't know”
  • Real testers, real feedback, before it ever reaches Launch

Part 3 · The prompting playbook

Prompting instincts check

Tip 1 & 2 · workflow habits

Two habits worth stealing

The copy-paste box

Don't hesitate to say: “give me the result in a box I can copy-paste.” A tiny formatting ask that saves a real re-typing tax, every time.

Search-and-replace, not global replace

When you're fixing something, point at the exact spot — don't ask for a full regeneration. Smaller diffs, fewer new problems introduced along the way.

Tip 3 · the one with actual math behind it

Everyone says “tell it what to do.” Try telling it what NOT to do.

  • A prompt carves out a target zone in an enormous space of possible answers
  • 3 things you ask for mostly overlap — each new one adds less (diminishing returns)
  • 3 things you forbid cut from 3 different directions — each removes fresh, independent territory

For the curious: this is set-complement logic (De Morgan) plus Shannon entropy — a negative constraint acts like an SVM separating hyperplane, slicing off a whole half-space at once.

Tip 4 · L'OréalGPT-specific

Write the prompt once, reuse it forever

  • Companion instructions accept dynamic variables — placeholders filled in automatically
  • Declare them at the top, then write the conditional rules that use them
  • One instruction set, correct for every country, every date, every user

Variables:
  {user.country}
  {current_date}

Rule:
  If {user.country} = "France",
  answer in French. Otherwise, English.

Tip 5 · the responsible-AI one

Demand the receipts

  • Ask exactly which document or data point an answer came from — if it can't say, treat it with suspicion
  • A confidence score is a statistical guess, not a guarantee — “92% sure” has been wrong before
  • Cross-check anything that would embarrass you if it were wrong, before it leaves the chat
